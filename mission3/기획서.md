# 더치페이 정산 및 내기 사다리 타기

## 대상 사용자

- **핵심 페르소나 (1순위 우선순위)**: 모임이나 회식 직후 식당 자리에서 스마트폰(가로 360px 화면)으로 총금액과 인원수를 빠르게 입력해 1인당 정산 금액과 입금 계좌번호를 계산하고, 사다리 타기로 자투리 금액(또는 커피 내기) 당첨자 1명을 뽑아 카카오톡 단톡방에 즉시 복사·공유해야 하는 **20~40대 모임 총무(직장인·동호회·스터디 총무)**.
- **보조 사용자 (2순위 우선순위)**: 총무와 함께 자리에서 스마트폰이나 노트북·태블릿 화면을 보며 자신의 출발 번호(1번~N번)를 직접 눌러 사다리 경로와 당첨 결과를 확인하는 **모임 참석자들(2~10명)**.

## 사용 목적

- 총금액을 인원수대로 똑같이 나눈 **1인당 정산 금액(1원 단위 내림)**과 나누어떨어지지 않는 **남는 자투리 금액(나머지)**을 오차 없이 계산하고, 입금 계좌번호와 함께 한 번에 복사해 공유합니다.
- 유쾌한 상호작용이 있는 사다리 타기로 내기 당첨 번호 딱 1명을 공정하게 뽑아, 정산 안내 문구에 당첨 결과까지 자동으로 담아 공유합니다.

## 화면 구성과 동작

- **전체 디자인 및 상하 화면 배치**:
  - 밝고 유쾌한 분위기(산뜻한 노란색·코랄·민트 포인트 색상, 둥근 모서리 카드, 직관적인 이모지)로 꾸며진 화면입니다. 맨 위에 ‘💸 더치페이 정산 & 내기 사다리 🎯’ 제목과 한 줄 안내가 있습니다.
  - 한 화면 안에서 위쪽에는 **‘🧮 1/N 똑같이 나누기 계산기’** 카드가, 아래쪽에는 **‘🪜 운명의 내기 사다리 타기’** 카드가 상하 순서대로 배치됩니다.
- **위쪽 ‘🧮 1/N 똑같이 나누기 계산기’ 카드 (정산 영역)**:
  - 모임 이름, 총금액(원), 참여 인원수(2~10명), 입금받을 은행명·계좌번호·예금주 입력칸이 있습니다. 처음 열었을 때 바로 눌러 볼 수 있도록 가상 예시 값이 기본으로 채워져 있습니다.
  - 숫자를 일일이 치지 않아도 되도록 총금액 칸 아래에 **`+10,000원`, `+50,000원`, `초기화` 빠른 금액 버튼**이 있고, 인원수 칸 옆에는 **`-` / `+` 증감 버튼**이 있어 누를 때마다 숫자와 계산 결과가 즉시 바뀝니다.
  - 금액이나 인원수가 바뀌면 총금액을 인원수로 나눈 **1인당 금액(1원 단위 내림)**과 나누어떨어지지 않고 **남는 자투리 금액(나머지)**이 강조 효과와 함께 표시됩니다. (예: 50,000원 ÷ 3명 → 1인당 16,666원 · 남는 자투리 금액 2원)
  - 계산 결과 아래에 말풍선 모양의 정산 안내 문구(모임 이름, 총금액, 인원수, 1인당 입금 금액, 남는 자투리, 사다리 당첨 번호(공개 시), 은행·계좌번호·예금주) 미리보기가 나타납니다.
  - **‘📋 정산 내용 + 계좌번호 복사하기’** 버튼을 누르면 버튼이 초록색으로 바뀌며 ‘✅ 복사 완료! 카톡이나 문자에 붙여넣으세요!’로 2초간 변하고, 클립보드에 문구가 복사됩니다. 자동 복사가 제한된 환경에서는 문구 상자가 선택되어 직접 복사하도록 안내합니다.
- **아래쪽 ‘🪜 운명의 내기 사다리 타기(당첨자 1명 뽑기)’ 카드 (사다리 영역)**:
  - 사다리 참여 인원수(2~10명, 위쪽 정산 인원수와 연동하거나 `-` / `+` 버튼으로 개별 조절 가능)와 **‘🎲 새 사다리 만들기’**, **‘⚡ 전체 결과 한 번에 보기’** 버튼이 있습니다.
  - ‘🎲 새 사다리 만들기’를 누르면 1번부터 N번까지 출발 번호 버튼과 세로줄, 무작위 가로줄이 그려지고 도착 지점 중 한 곳에 ‘🎯 당첨!’ 표시가 배치됩니다.
  - **상호작용(인터랙션) 및 피드백 반영 동작**:
    1. 위쪽의 출발 번호(1번~N번) 중 하나를 직접 누르면, 해당 번호에서 출발한 색깔 선이 사다리 가로줄을 따라 내려가는 애니메이션이 재생되고 도착 지점(통과 또는 당첨)이 밝혀집니다.
    2. ‘⚡ 전체 결과 한 번에 보기’ 버튼을 누르면 모든 번호의 경로와 최종 당첨 번호가 즉시 공개됩니다.
    3. 당첨 번호가 밝혀지면 화면에 색종이(폭죽) 애니메이션 효과와 함께 **‘🎉 오늘의 당첨 번호는 O번입니다!’** 배너가 통통 튀는 효과로 크게 표시됩니다.
    4. 당첨 번호가 공개되면 정산 공유 문구 미리보기에 `• 🎯 내기 사다리 당첨: O번` 줄이 자동으로 포함되며, 화면을 다시 맨 위로 스크롤하지 않고도 바로 복사할 수 있도록 당첨 배너 아래에 **‘📋 당첨 번호 포함 정산 문구 복사하기’** 버튼이 나타납니다.

## 필수 기능

1. **1/N 정산 및 남는 자투리 금액 실시간 계산**: 모임 이름, 총금액(원), 참여 인원수(2~10명), 입금 계좌(은행명·계좌번호·예금주)를 입력받아 `1인당 금액(원 단위 내림)`과 `남는 자투리 금액(나머지)`을 즉시 계산하고 화면에 표시하는 기능.
2. **빠른 금액 버튼 및 인원수 증감 버튼 조작**: 키보드 입력 없이도 금액을 빠르게 조정하는 `+10,000원`, `+50,000원`, `초기화` 버튼과 참여 인원수를 조절하는 `-` / `+` 버튼 기능(위쪽 정산 인원수 변경 시 아래쪽 사다리 인원수 자동 연동 포함).
3. **비정상 입력값 유효성 검사 및 오류 안내**: 총금액이 빈칸이거나 `0`원 이하일 때, 또는 인원수가 `2~10명` 범위를 벗어날 때 계산과 사다리 생성을 즉시 중단하고 흔들림 애니메이션과 함께 오류 안내 문구를 표시하는 기능.
4. **1대1 매칭 무작위 사다리 생성 및 경로 애니메이션**: 설정한 인원수(2~10명)만큼 세로줄과 인접 가로줄이 겹치지 않는 무작위 사다리를 그려 출발 번호(1번~N번)와 도착 칸이 1대1로 연결되게 하고, 개별 번호 클릭 시 경로 애니메이션 및 당첨자(1명) 배너·색종이 효과를 재생하는 기능.
5. **정산 내역·계좌번호·사다리 당첨 번호 원클릭 복사**: 정산 계산 결과와 입금 계좌 정보(및 사다리 당첨 번호 공개 시 당첨 번호)를 말풍선 미리보기로 조합하고, 상단 계산기 복사 버튼과 하단 사다리 당첨 배너 아래 복사 버튼을 통해 클립보드에 즉시 복사하는 기능.

## 추가 기능

- 카카오톡 공유 API(Kakao SDK)를 연동하여 버튼 한 번으로 카카오톡 채팅방에 정산 카드를 바로 전송하는 기능
- 차수별(1차 식사, 2차 카페 등) 금액과 참석자를 따로 입력해 합산 정산하는 기능
- 사다리 번호(1번~N번) 대신 참석자 이름과 캐릭터 아이콘을 직접 지정하고, 사다리 당첨자에게 남는 자투리 금액이나 전액을 자동으로 더해 1인당 금액 숫자를 차등 계산하는 기능
- 사다리 줄을 따라 내려갈 때 경쾌한 효과음과 당첨 팡파르 소리가 나는 기능
- 과거 정산 내역과 자주 쓰는 계좌번호를 브라우저(`localStorage`)에 저장해 불러오는 기능

## 필요한 자료

- 모임 이름, 총금액, 참여 인원수, 은행명·계좌번호·예금주 기본 샘플 데이터 (예: 모임 이름 ‘금요일 저녁 모임 🍕’, 총금액 ‘68,000원’, 인원수 ‘4명’, 계좌 ‘국민은행 123456-04-789012 홍길동(가상 예시)’)
- 하단에 기본 입력된 계좌 정보는 테스트용 가상 예시임을 알리는 안내 문구
- 외부 이미지 파일, 외부 글꼴, 외부 라이브러리를 인터넷에서 불러오지 않고, HTML·CSS 애니메이션·내장 스크립트(Canvas/SVG 및 이모지)만으로 화면과 사다리 경로, 색종이 효과를 구현합니다.

## 완료 기준

- **1. 초기 로드 및 기본 예시 표시**
  - **테스트 입력값**: HTML 파일 최초 열기 (`모임 이름: 금요일 저녁 모임 🍕`, `총금액: 68000`, `인원수: 4`, `계좌: 국민은행 123456-04-789012 홍길동(가상 예시)`)
  - **예상 출력**: `1인당 금액 17,000원`, `남는 자투리 금액 0원`, 공유 문구 미리보기 상자 표시
  - **성공/실패 기준(정량)**: 페이지 로드 즉시 추가 조작 없이 3개 출력 항목(1인당 금액 `17,000원`, 자투리 `0원`, 미리보기 4줄)이 100% 일치하면 성공, 빈칸이나 `NaN`이 노출되면 실패.
- **2. 빠른 금액 버튼 및 인원 증감 버튼 동작**
  - **테스트 입력값**: 기본 상태(`68000`, `4명`)에서 `+10,000원` 버튼 1회 클릭 후 인원 `+` 버튼 1회 클릭 (`총금액: 78000`, `인원수: 5`)
  - **예상 출력**: 총금액 입력칸 `78000`, 인원수 입력칸 `5`, `1인당 금액 15,600원`, `남는 자투리 금액 0원`, 사다리 인원수 `5` 연동
  - **성공/실패 기준(정량)**: 새로고침 없이 버튼 클릭 즉시 입력칸 숫자와 1인당 금액(`15,600원`) 및 사다리 세로줄 수(`5개`)가 모두 갱신되면 성공, 이전 값이 남아 있으면 실패.
- **3. 나누어떨어지지 않는 금액(1원 단위 내림 및 자투리) 계산**
  - **테스트 입력값**: `총금액: 50000`, `참여 인원수: 3` 입력
  - **예상 출력**: `1인당 금액 16,666원`, `남는 자투리 금액 2원`, 미리보기에 `• 1인당 입금 금액: 16,666원` 및 `• 남는 자투리: 2원` 표시
  - **성공/실패 기준(정량)**: 몫(`16,666원`)과 나머지(`2원`)가 `16,666 × 3 + 2 = 50,000` 수식과 1원 오차도 없이 일치하면 성공, 반올림(`16,667원`)되거나 소수점이 표시되면 실패.
- **4. 비정상 입력값(빈칸·0원 이하·범위 밖 인원) 차단 및 오류 안내**
  - **테스트 입력값**: ① `인원수: 1` 또는 `11` 입력 / ② `총금액: 0`, `-1000`, `빈칸("")` 입력 또는 `초기화` 버튼 클릭
  - **예상 출력**: ① `인원수는 2명에서 10명 사이로 설정해 주세요!` 표시 및 계산 결과 숨김 / ② `총금액을 1원 이상 입력해 주세요!` 표시 및 계산 결과 숨김
  - **성공/실패 기준(정량)**: 비정상 입력 5종(`인원 1`, `인원 11`, `금액 0`, `금액 -1000`, `금액 빈칸`) 모두에서 계산 상자가 숨겨지고 오류 안내 문구가 표시되면 성공(5/5건 통과), 1건이라도 `0원`이나 오류 없이 계산되면 실패.
- **5. 사다리 1대1 매칭 및 당첨 번호 1개 추출**
  - **테스트 입력값**: `사다리 인원수: 4` 설정 후 `🎲 새 사다리 만들기` 클릭 → `1번`~`4번` 출발 버튼 순차 클릭 및 `⚡ 전체 결과 한 번에 보기` 클릭
  - **예상 출력**: 4개의 색깔 경로 선이 가로줄을 따라 내려가 서로 다른 도착 칸(통과 3개, `🎯 당첨!` 1개)에 연결되고, `🎉 오늘의 당첨 번호는 O번입니다!` 배너 표시
  - **성공/실패 기준(정량)**: 출발 번호 4개의 도착 칸 중복이 `0건`(1대1 매칭 100%)이고 당첨 칸이 정확히 `1개`이며, 개별 클릭 결과와 전체 결과 보기의 당첨 번호가 일치하면 성공.
- **6. 정산 내역 + 계좌번호 + 사다리 당첨 번호 클립보드 복사**
  - **테스트 입력값**: `총금액: 50000`, `인원수: 3` 상태에서 사다리 당첨 번호(예: `2번`) 공개 후 하단 `📋 당첨 번호 포함 정산 문구 복사하기` 클릭 → 메모장 붙여 넣기(`Ctrl+V`)
  - **예상 출력**: 버튼 문구가 `✅ 복사 완료! 카톡이나 문자에 붙여넣으세요!`로 변하고, 메모장에 모임 이름·총금액(`50,000원`)·1인당 금액(`16,666원`)·남는 자투리(`2원`)·사다리 당첨(`2번`)·계좌 정보가 동일하게 붙여 넣어짐
  - **성공/실패 기준(정량)**: 화면 미리보기 텍스트와 메모장에 붙여 넣은 텍스트의 6개 필수 항목이 100% 일치하면 성공, 당첨 번호나 계좌가 누락되면 실패.
- **7. 모바일 좁은 화면(폭 360px) 10명 사다리 반응형 표시**
  - **테스트 입력값**: 브라우저 창 가로폭 `360px` 설정 후 `사다리 인원수: 10` 입력
  - **예상 출력**: 위쪽 계산기와 아래쪽 10명 사다리(`1번`~`10번` 출발 버튼 및 도착 칸 10개)가 한 화면 폭 안에 균등 축소되어 배치됨
  - **성공/실패 기준(정량)**: 가로폭 `360px`에서 페이지 및 사다리 영역의 가로 스크롤 발생이 `0건`(`scrollWidth <= clientWidth`)이고 `1번`~`10번` 버튼 10개가 잘림 없이 모두 보이고 클릭 가능하면 성공.
- **8. 단일 파일 오프라인 독립 실행**
  - **테스트 입력값**: 네트워크 연결을 차단한 상태에서 `더치페이.html` 단독 실행
  - **예상 출력**: 모든 스타일·계산·사다리 애니메이션·색종이 효과 정상 동작
  - **성공/실패 기준(정량)**: 외부 네트워크 요청 `0건` 및 브라우저 콘솔 오류 `0건`이면 성공.

## 한계 및 비목표

### 한계 (시스템 및 동작상의 제약 조건 3가지)
1. **참여 인원수(2~10명) 및 번호 표기 방식의 한계**: 참여 인원수는 최소 2명부터 최대 10명까지만 지원하며(1명 이하·11명 이상은 실행 차단), 사다리 타기는 참석자 실명 대신 `1번`~`10번` 숫자로만 진행하고 당첨자도 딱 1명만 뽑습니다. *(검증 방법 2와 연계)*
2. **균등 분할(1원 단위 내림) 수식의 한계**: 정산 계산기는 총금액을 인원수로 똑같이 나누는 `1/N` 계산만 수행하며, 1원 미만 소수점은 내림 처리하고 나누어떨어지지 않는 금액(1원~`N-1`원)은 별도의 ‘남는 자투리 금액’으로만 안내할 뿐 특정 인원의 입금 금액에 자동 합산하지 않습니다. *(검증 방법 1과 연계)*
3. **데이터 휘발성 및 브라우저 클립보드 권한의 한계**: 별도 서버나 브라우저 저장소를 사용하지 않으므로 창을 닫거나 새로고침(`F5`)하면 입력한 모든 내용과 사다리 결과가 초기 예시 상태로 돌아가며, 클립보드 자동 복사 권한이 제한된 환경에서는 문구 상자가 자동 선택되어 사용자가 직접 복사(`Ctrl+C`)해야 합니다. *(검증 방법 3과 연계)*

### 비목표 (의도적으로 구현하지 않는 영역 3가지)
1. **개인별·메뉴별 차등 정산 및 다차수 합산 비목표**: 메뉴별 개별 금액 계산, 술을 마시지 않은 참석자 차등 정산, 1차·2차 영수증 합산 정산 기능은 구현하지 않고 빠른 `총금액 ÷ 인원수` 계산에만 집중합니다. *(검증 방법 1과 연계)*
2. **외부 메신저 자동 발송 API 연동 비목표**: 카카오톡 등 외부 SNS 앱으로 직접 메시지를 발송하는 API 연동은 구현하지 않으며, 복사 버튼을 누른 뒤 사용자가 직접 메신저 대화창에 붙여 넣는 방식으로 공유합니다. *(검증 방법 3과 연계)*
3. **실제 계좌 유효성 조회 및 송금·결제 처리 비목표**: 입력한 은행명·계좌번호·예금주의 실명 유효성을 금융망으로 확인하거나 실제 송금·결제를 처리하는 기능은 제공하지 않으며, 안내 문구 생성만 수행합니다. *(검증 방법 3과 연계)*

## 검증 방법

- **검증 방법 1 (정산 수식 및 균등 분할 한계·차등 정산 비목표 검증)**: 나누어떨어지는 금액(`68,000원 ÷ 4명 = 17,000원, 자투리 0원`)과 나누어떨어지지 않는 금액(`50,000원 ÷ 3명 = 16,666원, 자투리 2원`)을 손이나 별도 계산기로 먼저 계산한 뒤, 페이지에 표시된 ‘1인당 금액’·‘남는 자투리 금액’과 1원 단위까지 대조합니다(한계 2·비목표 1 검증). 또한 총금액에 `0`원·빈칸·음수를 입력했을 때 `0원`으로 계산되지 않고 안내 문구가 표시되는지 확인합니다.
- **검증 방법 2 (사다리 1대1 매칭 및 인원 한계·반응형 검증)**: 인원수에 `1명`, `11명`을 입력해 차단 안내가 뜨는지 확인하고(한계 1 검증), 기본 `4명` 및 휴대폰 폭(`360px`)에서의 최대 인원 `10명` 사다리를 생성한 뒤 `1번`부터 `N번`까지 색칠되는 경로를 눈으로 직접 따라가 보며 모든 출발 번호가 서로 다른 도착 칸에 1대1로 연결되는지, 가로 스크롤 없이 당첨 번호 딱 1개가 발표되는지 대조합니다.
- **검증 방법 3 (클립보드 복사 및 외부 연동·송금 비목표·휘발성 한계 검증)**: 사다리 당첨 번호 공개 후 하단의 ‘📋 당첨 번호 포함 정산 문구 복사하기’ 버튼을 눌러 메모장에 붙여 넣은 텍스트가 화면 미리보기(모임 이름, 총금액, 인원수, 1인당 금액, 남는 자투리, 사다리 당첨 번호, 계좌 정보)와 일치하는지 대조하고(비목표 2·3 검증), 브라우저를 새로고침(`F5`)했을 때 모든 입력값이 초기 예시(`68,000원`, `4명`)로 초기화되는지 확인합니다(한계 3 검증).
