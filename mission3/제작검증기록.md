## 수정 기록

### 수정 기록 1 (좁은 화면 360px에서 10명 사다리 가로 잘림 해결)
- **발견한 문제**: 브라우저 화면 가로폭을 휴대폰 크기(`360px`)로 줄이고 사다리 인원수를 최대 인원인 `10명`으로 설정해 실행했더니(테스트 내용), 1번부터 10번까지 출발 버튼과 도착 칸이 한 화면 안에 모두 보일 줄 알았는데(예상 결과), 버튼 최소 너비(`44px`) 때문에 사다리 영역(`clientWidth: 312px`)의 내부 폭이 `494px`로 늘어나 가로 스크롤이 생기고 오른쪽 9번·10번 버튼과 도착 칸이 화면 밖으로 밀려 한눈에 보이지 않았습니다(실제 결과).
- **AI에게 전달한 요청**: “화면 폭을 360px로 줄이고 사다리 인원수를 10명으로 바꾸면 사다리 영역에 가로 스크롤이 생겨서 9번, 10번 버튼이 잘려 보여. 기획서에는 휴대폰 폭(360px)에서 10명 사다리도 가로 스크롤이나 잘림 없이 한 화면에서 조작할 수 있다고 적었어. 인원수에 맞춰 번호 버튼과 도착 칸 너비가 자동으로 줄어들도록 이 부분만 고치고, 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘.”
- **저장한 버전**: [`더치페이_v1.html`](./더치페이_v1.html) → [`더치페이_v2.html`](./더치페이_v2.html) (버전 라벨: `v2.0`)
- **수정 후 테스트 결과**: 같은 조건(`360px` 화면, `10명` 사다리)으로 다시 테스트하니 1번~10번 출발 버튼과 도착 칸이 칸 수(`--cols: 10`)에 맞춰 균등하게 줄어들어 가로 스크롤 없이(`scrollWidth = clientWidth = 312px`) 한 화면에 모두 표시되었고, 10번 버튼을 눌렀을 때 사다리 경로도 정상적으로 내려갔습니다. 기존에 잘 되던 `50,000원 ÷ 3명` 계산(`16,666원`, 남는 자투리 `2원`)과 계좌 복사 기능도 다시 테스트해 전과 같이 동작함을 확인했습니다.
- **수정 이유**: 식당이나 모임 자리에서는 주로 휴대폰으로 화면을 같이 보며 번호를 고르는데, 인원이 많을 때 오른쪽 번호가 잘려 옆으로 밀어야 하면 끝에 있는 참석자가 번호를 누르거나 경로를 따라가기가 불편합니다.

### 수정 기록 2 (총금액 ‘초기화’ 및 0원·빈칸 입력 시 0원 계산 오류 해결)
