# Codyssey-02

코디세이(Codyssey) AI 네이티브 교육 과정 실습 프로젝트 (**더치페이 정산 & 내기 사다리**) 저장소입니다.

## 📂 폴더 구성

- **`mission1/` — AI와 함께 HTML 페이지 기획서 작성하기**
  - `기획서.md`: 더치페이 정산 계산기 및 내기 사다리 타기 웹페이지 기획서
- **`mission2/` — 두 AI로 HTML 만들고 테스트하기**
  - `기획서.md`: 미션 1에서 작성한 기획서
  - `더치페이_v1.html`: 두 AI 결과물 비교 후 선택한 초기 버전 HTML
  - `제작검증기록.md`: 두 AI 비교 결과, 선택 근거, 완료 기준에 따른 테스트 3건 기록
- **`mission3/` — 테스트하며 고치고 사용자 피드백 반영하기**
  - `더치페이_v1.html` ~ `더치페이_v4.html`: 문제 해결 및 사용자 피드백 단계별 버전 파일
  - `더치페이.html`: 최종 완성된 단일 HTML 파일 (CSS·JavaScript 내장)
  - `기획서.md`: 최종 HTML 동작에 맞춰 업데이트한 최종 기획서
  - `제작검증기록.md`: 두 AI 비교, 테스트 3건, 수정 기록 3건, 사용자 테스트 및 피드백 반영 기록
