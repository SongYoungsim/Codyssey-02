## 수정 기록

### 수정 기록 1
- 발견한 문제: 브라우저 화면 가로폭을 휴대폰 크기(360px)로 줄이고 사다리 인원수를 최대 인원인 10명으로 설정해 실행했더니(테스트 내용), 1번부터 10번까지 버튼과 도착 칸이 한 화면 안에 모두 보일 줄 알았는데(예상 결과), 버튼 최소 너비(44px) 때문에 사다리 영역에 가로 스크롤이 생기고 오른쪽 9번·10번 버튼과 도착 칸이 화면 밖으로 밀려 한눈에 보이지 않았습니다(실제 결과).
- AI에게 전달한 요청: “화면 폭을 360px로 줄이고 사다리 인원수를 10명으로 바꾸면 사다리 영역에 가로 스크롤이 생겨서 9번, 10번 버튼이 잘려 보여. 기획서에는 휴대폰 폭(360px)에서 10명 사다리도 가로 스크롤이나 잘림 없이 한 화면에서 조작할 수 있다고 적었어. 인원수에 맞춰 번호 버튼과 도착 칸 너비가 자동으로 줄어들도록 이 부분만 고치고, 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘.”
- 저장한 버전: `더치페이_v1.html` → `더치페이_v2.html`
- 수정 후 테스트 결과: 같은 조건(360px 화면, 10명 사다리)으로 다시 테스트하니 1번~10번 출발 버튼과 도착 칸이 칸 수에 맞춰 균등하게 줄어들어 가로 스크롤 없이 한 화면에 모두 표시되었고, 10번 버튼을 눌렀을 때 사다리 경로도 정상적으로 내려갔습니다. 기존에 잘 되던 50,000원 ÷ 3명 계산(16,666원, 남는 자투리 2원)과 계좌 복사 기능도 다시 테스트해 전과 같이 동작함을 확인했습니다.
- 수정 이유: 식당이나 모임 자리에서는 주로 휴대폰으로 화면을 같이 보며 번호를 고르는데, 인원이 많을 때 오른쪽 번호가 잘려 옆으로 밀어야 하면 끝에 있는 참석자가 번호를 누르거나 경로를 따라가기가 불편합니다.

### 수정 기록 2
- 발견한 문제: 새로운 금액을 입력하려고 총금액 아래의 ‘초기화’ 버튼을 눌러 금액을 `0`으로 만들거나 총금액 입력칸의 숫자를 모두 지워 빈칸으로 두었더니(테스트 내용), 계산을 멈추고 ‘총금액을 1원 이상 입력해 주세요!’ 안내 문구가 나올 줄 알았는데(예상 결과), 안내 문구 없이 ‘1인당 금액 0원 · 남는 자투리 금액 0원’으로 계산 결과와 미리보기 문구가 그대로 표시되었습니다(실제 결과).
- AI에게 전달한 요청: “총금액에서 ‘초기화’ 버튼을 눌러 0원이 되거나 입력칸을 빈칸으로 지우면 안내 문구가 안 나오고 ‘1인당 금액 0원’으로 계산돼. 기획서 완료 기준에는 총금액에 0 이하를 입력하면 계산을 멈추고 ‘총금액을 1원 이상 입력해 주세요!’ 안내 문구가 나온다고 적었어. 이 부분만 고치고 다른 기능은 그대로 유지해서 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘.”
- 저장한 버전: `더치페이_v2.html` → `더치페이_v3.html`
- 수정 후 테스트 결과: ‘초기화’ 버튼을 누르거나 총금액 칸에 `0`, `-1000`, 빈칸을 입력하니 계산 결과 상자와 미리보기가 숨겨지고 흔들림 효과와 함께 ‘총금액을 1원 이상 입력해 주세요!’ 안내 문구가 나타났습니다. 다시 `+50,000원` 버튼을 누르니 즉시 안내 문구가 사라지고 정상 계산되었습니다. 수정 기록 1에서 고친 360px 10명 사다리 화면과 4명 사다리 경로 테스트도 다시 확인해 이상이 없었습니다.
- 수정 이유: 금액을 새로 입력하려고 초기화하거나 지웠을 때 ‘1인당 0원’이 정상 정산 문구처럼 남아 있으면, 총무가 실수로 0원 안내 문구를 그대로 복사해 단체 대화방에 공유할 수 있습니다.

### 수정 기록 3
- 발견한 문제: 모임 총무를 맡아 본 동료에게 총금액 50,000원을 3명으로 나누고 남는 자투리 2원을 낼 사람을 사다리로 뽑아 단톡방 공유용 문구를 복사해 달라고 요청했더니(테스트 내용), 사다리 결과를 확인한 뒤 편하게 공유 문구를 복사할 줄 알았는데(예상 결과), 아래쪽 사다리에서 당첨 번호를 확인한 뒤 복사 버튼을 찾느라 다시 화면 맨 위로 스크롤해 올라갔고, 메모장에 붙여 넣은 문구에 사다리 당첨 번호가 적혀 있지 않자 “사다리에서 뽑은 당첨 번호는 왜 같이 복사 안 돼요?”라고 물었습니다(실제 결과).
- AI에게 전달한 요청: “아래쪽에서 사다리 당첨 번호가 나오면 위쪽 공유 문구 미리보기에도 ‘• 🎯 내기 사다리 당첨: O번’ 줄이 자동으로 추가되게 해 줘. 그리고 사다리 당첨 배너 바로 아래에도 ‘📋 당첨 번호 포함 정산 문구 복사하기’ 버튼을 보여 줘서, 사다리를 뽑은 뒤 화면 맨 위로 다시 올라가지 않고 바로 복사할 수 있게 고쳐 줘. 기존 기능은 그대로 유지하고 고친 HTML 파일 전체를 다시 보여 줘.”
- 저장한 버전: `더치페이_v3.html` → `더치페이_v4.html`
- 수정 후 테스트 결과: 아래쪽 사다리에서 출발 번호를 눌러 당첨 번호(예: 2번)가 공개되자, 당첨 배너 바로 아래에 ‘📋 당첨 번호 포함 정산 문구 복사하기’ 버튼이 나타났고, 이를 눌러 메모장에 붙여 넣으니 정산 금액·계좌번호와 함께 `• 🎯 내기 사다리 당첨: 2번`이 한 번에 복사되었습니다. ‘🎲 새 사다리 만들기’를 누르면 당첨 확정 전까지 해당 줄과 하단 복사 버튼이 다시 숨겨지는 것도 확인했습니다. 기존 50,000원 ÷ 3명 계산, 0원 입력 안내, 360px 10명 사다리 표시도 모두 정상 동작했습니다.
- 수정 이유: 위쪽에서 정산 계산을 마치고 아래쪽으로 내려와 사다리를 뽑는 흐름인데, 결과를 본 뒤 다시 위로 스크롤해 올라가야 하고 당첨 번호까지 손으로 따로 적어야 하면 한 화면에 두 기능을 합쳐 둔 장점이 줄어듭니다.
