# 더치페이 정산 및 내기 사다리 타기

## 대상 사용자

- 모임이나 식사 후 총무를 맡아 참석자들에게 정산 금액과 계좌번호를 안내하거나, 사다리 타기로 내기 당첨자를 뽑으려는 나와 모임 참석자들. 주로 휴대폰이나 노트북 브라우저에서 바로 열어 사용합니다.
- 모임이나 회식 자리에서 총무를 맡아 참석자들에게 정산 금액과 계좌번호를 공유하거나, 다 같이 화면을 보며 재미있게 내기(커피·자투리 금액 쏘기 등) 당첨자를 뽑으려는 나와 모임 참석자들. 모임 현장에서는 휴대폰으로, 자리에서는 노트북이나 태블릿으로 열어 사용합니다.

## 사용 목적

- 총금액을 인원수대로 똑같이 나눈 1인당 정산 금액과 입금 계좌번호를 한 번에 정리해 복사하거나, 내기 사다리 타기로 당첨 번호 1명을 뽑습니다.
- 총금액을 인원수대로 나눈 1인당 정산 금액과 입금 계좌번호를 한 번에 계산·복사해 공유하고, 유쾌한 상호작용이 있는 사다리 타기로 내기 당첨 번호 1명을 뽑습니다.

## 화면 구성과 동작

- 맨 위에 페이지 제목 ‘더치페이 정산 & 내기 사다리’가 있고, 화면은 위쪽의 **‘1/N 똑같이 나누기 계산기’** 영역과 아래쪽의 **‘내기 사다리 타기(당첨자 1명 뽑기)’** 영역으로 나뉩니다.
- **위쪽 ‘1/N 똑같이 나누기 계산기’ 영역**:
  - 모임 이름, 총금액(원), 참여 인원수(2~10명), 입금받을 은행명·계좌번호·예금주 입력칸이 있습니다. 처음 열었을 때 바로 시험해 볼 수 있도록 가상 예시 값이 기본으로 채워져 있습니다.
  - ‘정산 계산하기’ 버튼을 누르면(또는 금액·인원수를 바꾸면) 총금액을 인원수로 나눈 **1인당 금액(1원 단위 내림)**과 나누어떨어지지 않고 **남는 자투리 금액(나머지)**이 표시됩니다. (예: 50,000원 ÷ 3명 → 1인당 16,666원 · 남는 금액 2원)
  - 계산 결과 아래에 복사할 정산 안내 문구(모임 이름, 총금액, 인원수, 1인당 입금 금액, 은행·계좌번호·예금주)가 미리보기로 나타납니다.
  - ‘정산 내용 + 계좌번호 복사’ 버튼을 누르면 미리보기 문구가 클립보드에 복사되고, 화면에 ‘정산 내용과 계좌번호를 복사했습니다. 문자나 메신저에 붙여 넣어 공유하세요.’ 안내가 나타납니다. 자동 복사가 지원되지 않는 환경에서는 문구를 직접 선택해 복사하도록 안내합니다.
- **아래쪽 ‘내기 사다리 타기(당첨자 1명 뽑기)’ 영역**:
  - 사다리 참여 인원수 입력칸(2~10명, 위쪽 정산 인원수와 연동하거나 직접 변경 가능)과 ‘사다리 만들고 결과 보기’ 버튼이 있습니다.
  - 인원수를 정하고 버튼을 누르면 1번부터 N번까지의 세로줄과 무작위 가로줄이 있는 사다리가 그려지고, 도착 지점 중 한 곳에 ‘당첨(내기)’ 표시가 나타납니다.
  - 각 번호에서 사다리 줄을 따라 내려간 최종 결과와 함께 ‘당첨 번호는 O번입니다!’ 문구가 강조되어 표시됩니다. ‘다시 뽑기’ 버튼을 누르면 가로줄과 당첨 위치가 새로 섞입니다.
- **전체 디자인 및 반응형 구성**:
  - 밝고 유쾌한 분위기(산뜻한 노란색·코랄·민트 포인트 색상, 둥근 모서리 카드, 직관적인 이모지)로 꾸며진 화면입니다. 맨 위에 ‘💸 오늘 정산 & 운명의 사다리 🎯’ 제목과 유쾌한 한 줄 안내가 있습니다.
  - **반응형 화면 배치**: 컴퓨터·태블릿 등 넓은 화면(가로 768px 이상)에서는 왼쪽에 **‘1/N 똑같이 나누기 계산기’**, 오른쪽에 **‘운명의 내기 사다리 타기’** 카드가 2단으로 나란히 보이고, 휴대폰 등 좁은 화면(가로 768px 미만)에서는 위·아래 1단 세로 배치로 자동 전환됩니다.
- **‘1/N 똑같이 나누기 계산기’ 카드 (정산 영역)**:
  - 모임 이름, 총금액(원), 참여 인원수(2~10명), 입금받을 은행명·계좌번호·예금주 입력칸이 있습니다. 처음 열었을 때 바로 눌러 볼 수 있도록 가상 예시 값이 기본으로 채워져 있습니다.
  - 숫자를 일일이 치지 않아도 되도록 총금액 칸 아래에 **`+10,000원`, `+50,000원`, `초기화` 빠른 금액 버튼**이 있고, 인원수 칸 옆에는 **`-` / `+` 증감 버튼**이 있어 누를 때마다 숫자와 계산 결과가 즉시 바뀝니다.
  - 금액이나 인원수가 바뀌면 총금액을 인원수로 나눈 **1인당 금액(1원 단위 내림)**과 나누어떨어지지 않고 **남는 자투리 금액(나머지)**이 숫자가 커지는 강조 효과와 함께 표시됩니다. (예: 50,000원 ÷ 3명 → 1인당 16,666원 · 남는 자투리 2원)
  - 계산 결과 아래에 말풍선 모양의 정산 안내 문구(모임 이름, 총금액, 인원수, 1인당 입금 금액, 은행·계좌번호·예금주) 미리보기가 나타납니다.
  - **‘📋 정산 내용 + 계좌번호 복사하기’** 버튼을 누르면 버튼이 초록색으로 바뀌며 ‘✅ 복사 완료! 카톡이나 문자에 붙여넣으세요!’로 2초간 변하고, 클립보드에 문구가 복사됩니다. 자동 복사가 안 되는 환경에서는 문구 상자가 선택되어 직접 복사하도록 안내합니다.
- **‘운명의 내기 사다리 타기(당첨자 1명 뽑기)’ 카드 (사다리 영역)**:
  - 사다리 인원수(2~10명, 정산 인원수와 연동하거나 `-` / `+` 버튼으로 조절 가능)와 **‘🎲 새 사다리 만들기’**, **‘⚡ 전체 결과 한 번에 보기’** 버튼이 있습니다.
  - ‘🎲 새 사다리 만들기’를 누르면 1번부터 N번까지 출발 번호 버튼과 세로줄, 무작위 가로줄이 그려지고 도착 지점 중 한 곳에 ‘🎯 당첨!’ 폭탄/선물 표시가 배치됩니다.
  - **상호작용(인터랙션) 동작**:
    1. 위쪽의 출발 번호(1번~N번) 중 하나를 직접 누르면, 해당 번호에서 출발한 색깔 선이 사다리 가로줄을 따라 내려가는 애니메이션이 재생되고 도착 지점(통과 또는 당첨)이 밝혀집니다.
    2. ‘⚡ 전체 결과 한 번에 보기’ 버튼을 누르면 모든 번호의 경로와 최종 당첨 번호가 즉시 공개됩니다.
    3. 당첨 번호가 밝혀지면 화면에 색종이(폭죽) 애니메이션 효과와 함께 **‘🎉 오늘의 당첨 번호는 O번입니다!’** 배너가 통통 튀는 효과로 크게 표시됩니다.

## 필요한 자료

- 모임 이름, 총금액, 참여 인원수, 은행명·계좌번호·예금주 기본 샘플 데이터 (예: 모임 이름 ‘금요일 저녁 모임’, 총금액 ‘68,000원’, 인원수 ‘4명’, 계좌 ‘국민은행 123456-04-789012 홍길동(가상 예시)’)
- 모임 이름, 총금액, 참여 인원수, 은행명·계좌번호·예금주 기본 샘플 데이터 (예: 모임 이름 ‘금요일 저녁 모임 🍕’, 총금액 ‘68,000원’, 인원수 ‘4명’, 계좌 ‘국민은행 123456-04-789012 홍길동(가상 예시)’)
- 하단에 기본 입력된 계좌 정보는 테스트용 가상 예시임을 알리는 안내 문구
- 외부 이미지, 웹 글꼴, 외부 자바스크립트 라이브러리는 사용하지 않고 HTML 기본 요소와 CSS, 내장 스크립트만으로 화면과 사다리를 그립니다.
- 외부 이미지 파일, 외부 글꼴, 외부 라이브러리를 인터넷에서 불러오지 않고, HTML·CSS 애니메이션·내장 스크립트(Canvas/SVG 및 이모지)만으로 유쾌한 그래픽과 색종이 효과를 구현합니다.

## 완료 기준

- HTML 파일을 열면 기본 예시 값(68,000원, 4명, 가상 계좌 정보)이 채워져 있고, 1인당 정산 금액(17,000원)과 정산 안내 문구 미리보기를 바로 확인할 수 있습니다.
- 총금액에 `50000`, 인원수에 `3`을 입력하고 계산하면 1인당 금액 `16,666원`과 남는 금액 `2원`이 화면에 표시됩니다.
- 인원수에 2명 미만이나 10명 초과 값(예: `1` 또는 `11`), 혹은 총금액에 `0` 이하의 값을 입력하면 계산이나 사다리 생성을 멈추고 ‘인원수는 2명에서 10명 사이로 입력해 주세요.’ 또는 ‘올바른 총금액을 입력해 주세요.’ 안내 문구가 나옵니다.
- ‘정산 내용 + 계좌번호 복사’ 버튼을 누른 뒤 메모장에 붙여 넣으면 화면에 표시된 모임 이름, 총금액, 인원수, 1인당 금액, 은행명·계좌번호·예금주와 똑같은 텍스트가 붙여 넣어집니다.
- 사다리 타기에서 인원수(2~10명)를 설정하고 실행하면 설정한 인원수만큼 세로줄(1번~N번)이 그려지고, 출발 번호와 도착 결과가 1대1로 겹치지 않게 연결되며 당첨 번호 딱 1개가 표시됩니다.
- 휴대폰(가로폭 360px 기준)에서 열어도 위쪽 정산 계산기와 아래쪽 10명 사다리가 화면 밖으로 잘리지 않고 읽고 누를 수 있습니다.
- 다른 파일이나 로그인, 인터넷 연결 없이 HTML 파일 하나로 열리고 모든 기능이 동작합니다.
- HTML 파일을 열면 기본 예시 값(68,000원, 4명, 가상 계좌)이 채워져 있고, 1인당 정산 금액(17,000원)과 말풍선 모양의 정산 문구 미리보기를 바로 확인할 수 있습니다.
- 빠른 금액 버튼(`+10,000원`)이나 인원수 `-` / `+` 버튼을 누르면 입력칸의 숫자와 1인당 정산 금액이 새로고침 없이 즉시 바뀝니다.
- 총금액에 `50000`, 인원수에 `3`을 입력하면 1인당 금액 `16,666원`과 남는 자투리 금액 `2원`이 화면에 표시됩니다.
- 인원수를 2명 미만이나 10명 초과로 입력하거나 총금액에 `0` 이하를 입력하면, 흔들림 효과와 함께 ‘인원수는 2명에서 10명 사이로 설정해 주세요!’ 또는 ‘총금액을 1원 이상 입력해 주세요!’ 안내 문구가 나타납니다.
- ‘📋 정산 내용 + 계좌번호 복사하기’ 버튼을 누르면 버튼 문구가 복사 완료 상태로 바뀌고, 메모장에 붙여 넣었을 때 화면의 모임 이름, 총금액, 인원수, 1인당 금액, 은행·계좌번호·예금주와 똑같은 텍스트가 나옵니다.
- 사다리 타기에서 출발 번호(1번~N번)를 클릭하면 사다리 줄을 따라 내려가는 경로 색상이 표시되고, 당첨 번호가 공개될 때 축하 강조 효과와 함께 당첨 번호 딱 1개가 표시됩니다.
- **반응형 확인**: 브라우저 창 가로폭을 900px 이상(데스크톱)으로 넓히면 정산 카드와 사다리 카드가 좌우 2단으로 나란히 배치되고, 가로폭을 360px(휴대폰)로 줄이면 상하 1단으로 바뀐 뒤 10명 사다리까지 가로 스크롤이나 잘림 없이 한 화면 안에서 조작할 수 있습니다.
- 다른 파일이나 로그인, 인터넷 연결 없이 HTML 파일 하나로 열리고 모든 상호작용 기능이 동작합니다.

## 추가 기능

- 카카오톡 공유 API(Kakao SDK)를 연동하여 버튼 한 번으로 카카오톡 채팅방에 정산 카드를 바로 전송하는 기능
- 차수별(1차 식사, 2차 카페 등) 금액과 참석자를 따로 입력해 합산 정산하는 기능
- 사다리 번호 대신 참석자 이름을 직접 입력하고, 사다리 당첨자에게 남는 자투리 금액이나 전액을 자동으로 배정해 정산 문구에 반영하는 기능
- 과거 정산 내역과 자주 쓰는 계좌번호를 저장해 불러오는 기능
- 사다리 번호(1번~N번) 대신 참석자 이름과 캐릭터 아이콘을 직접 지정하고, 사다리 당첨자에게 남는 자투리 금액이나 전액을 자동으로 더해 정산 문구에 반영하는 기능
- 사다리 줄을 따라 내려갈 때 경쾌한 효과음과 당첨 팡파르 소리가 나는 기능
- 과거 정산 내역과 자주 쓰는 계좌번호를 브라우저에 저장해 불러오는 기능

## 한계 및 비목표

1. 참여 인원수는 최소 2명부터 최대 10명까지만 지원하며, 사다리 타기는 이름을 입력받지 않고 1번~10번 숫자로만 진행합니다.
2. 카카오톡 등 외부 SNS 앱으로 직접 메시지를 전송하는 API 연동 기능은 구현하지 않습니다. 공유는 복사를 누른 뒤 사용자가 직접 문자나 카카오톡 대화창에 붙여 넣는 방식으로 합니다.
2. 카카오톡 등 외부 SNS 앱으로 직접 메시지를 보내는 API 연동 기능은 구현하지 않습니다. 공유는 복사를 누른 뒤 사용자가 직접 문자나 카카오톡 대화창에 붙여 넣는 방식으로 합니다.
3. 입력한 계좌번호의 실제 유효성 확인, 송금 처리, 정산 기록 저장 기능은 제공하지 않습니다. 브라우저 창을 닫거나 새로고침하면 입력한 내용은 초기 예시 상태로 돌아갑니다.

## 검증 방법

- 나누어떨어지는 금액(예: `68,000원 ÷ 4명 = 17,000원, 나머지 0원`)과 나누어떨어지지 않는 금액(예: `50,000원 ÷ 3명 = 16,666원, 나머지 2원`)을 손이나 별도 계산기로 직접 계산한 뒤, 페이지에 표시된 ‘1인당 금액’·‘남는 금액’ 및 복사하여 메모장에 붙여 넣은 정산 문구의 숫자와 항목별로 대조합니다. 또한 사다리 타기에서 1번부터 N번까지 그려진 가로줄을 눈으로 직접 따라가 보며 화면 하단에 발표된 당첨 번호와 실제 사다리 경로가 일치하는지 확인합니다.
